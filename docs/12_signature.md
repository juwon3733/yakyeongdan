# 12. 동료 특색과 「터지는 맛」 재설계

사용자 피드백: "카드 구성은 좋은데 특색이 부족하고 뽕맛이 떨어져 재미없을 듯."
지금 동료들은 키워드 카드가 조금씩 세질 뿐, **한 판에 "이 동료로 이겼다"고 느낄 순간**이 없다. 이 문서는 모든 동료에게 같은 틀(쌓기 → 각성 → 터지는 턴)을 씌우고, 동료마다 다른 동료가 절대 못 하는 규칙을 하나씩 준다.

- 궁극기 카드는 만들지 않는다(사용자 결정). 터지는 맛은 카드가 아니라 **각성 상태**와 **카드끼리의 곱셈**에서 나온다.
- 이 문서는 설계안이다. 수치는 구현 뒤 `tools/sim.mjs`로 맞춘다.

---

## 1. 공통 틀

### 1-1. 쌓기: 고유 게이지
- 동료마다 **눈에 보이는 고유 게이지** 하나. 이름과 모양이 그 동료답다(아이리스 「칼끝」은 칼날 6칸, 브릭 「탄창」은 탄알 6개, 노엘 「꿈」은 양 5마리…).
- 그 동료의 키워드 행동으로 찬다(아래 표). 다른 동료 카드로는 거의 안 찬다 → "이 동료를 굴려야 이 동료가 터진다".
- 게이지는 전투 화면 동료 초상 바로 아래. 한 칸 찰 때마다 작은 소리, 다 차면 초상이 동료 색으로 빛나고 **[각성]** 버튼이 뜬다.
- 전투가 시작하면 0. **강적·보스전은 절반 찬 상태로 시작**.
- 게이지 크기는 4~8칸. 평범하게 굴리면 **전투 3~4턴째에 한 번** 찬다.

### 1-2. 각성
- 게이지가 차면 **언제 켤지 플레이어가 고른다**(내 턴 중 아무 때나, 에너지 0). 자동으로 켜지지 않는다 → 타이밍이 판단.
- 각성은 **2턴**(켠 턴 + 다음 내 턴). 그동안 그 동료는 **자기 규칙을 깨는 강한 변화**를 얻는다(아래 표).
- 각성 진입 시:
  - 컷인 1초(★3·★4는 가로 컷인, **★5는 전신 CG**). 누르면 건너뜀. 같은 전투 두 번째부터는 0.4초 짧은 판.
  - **연계가 바로 3칸**.
  - 전투곡 위에 그 동료 **테마 층**(8마디 리프)이 겹쳐 깔린다. 각성이 끝나면 빠짐.
  - 화면 테두리가 동료 색으로 빛나고, 그 동료 카드 테두리가 반짝인다.
- 횟수: **일반 전투 1번, 강적·보스전 2번**(두 번째는 게이지를 처음부터 다시 채워야 함).
- 쓰러지면 게이지는 남지만 각성은 즉시 끝난다.

### 1-3. 공명: 인연 짝이 같이 각성
- 인연 짝 두 사람의 각성 기간이 **겹치면 「공명」**.
  - 그 짝의 인연 듀오 카드가 손패에 바로 들어온다(이번 전투에 이미 썼어도 한 번 더).
  - 공명 중 그 듀오는 **비용 0, 효과 2배**, 전용 공명 컷인(두 사람 컷인을 한 화면에, ★5가 끼면 CG).
- 세 명 모두 각성이 겹치면 **「야경」**: 1턴 동안 모든 카드 비용 -1, 화면 전체 연출(밤하늘에 별이 쏟아짐). 판에 한 번 볼까 말까 한 순간으로 설계.

### 1-4. 터지는 턴
- 목표: 보통 판에서 **한 턴 피해 100 이상이 3~5번**. 대부분 각성 턴이나 공명 턴.
  - ★3 각성 턴 60~100, ★4 80~130, ★5 120~250.
- 카드 수치는 지금처럼 더하기(+3, +4)가 아니라 **곱하기 고리**가 하나씩 있게 고친다(장전×, 마력×, 베기 수×, 정령×행동 횟수…). 각성은 그 고리의 **상한을 없애거나 소모를 막는** 쪽으로 작동한다.
- 100이 넘는 피해는 숫자를 크게, 화면을 잠깐 멈추고(히트스톱 0.15초), 효과음을 한 단계 올린다. 200 넘으면 숫자가 화면을 가로지른다.
- 결과 화면에 **「오늘 밤 최고의 한 턴」**(턴 피해, 쓴 카드 순서, 각성한 동료) 기록. 도감 기록에도 동료별 최고 턴.

### 1-5. 특색 원칙
- 20명 각자 **다른 동료가 절대 못 하는 규칙 하나**(아래 「특색」 열). 겹치던 것들을 정리했다:
  | 겹치던 것 | 정리 |
  |---|---|
  | 밤 시계 되돌리기(엘레오노르·세바스) | **엘레오노르만**. 세바스 시계 카드 2장은 손패 카드로 바꿈 |
  | 첫 턴 연계 1칸(미미·모모·핀) | 미미·모모만 유지. 핀은 「인연 아닌 짝에도 다리 놓기」로 |
  | 별빛 쓰기·벌기(마리아나·후쿠로) | 마리아나 = 별빛을 **확정적으로** 힘으로. 후쿠로 = **무작위 대박** |
  | 대신 맞기(마르타·시그룬) | 마르타만 노림 끌기. 시그룬은 「노림에서 빠지기」 |
  | 베기(아이리스·아카네) | 공유는 유지(인연 근거). 아이리스 = 베기 **횟수**, 아카네 = **화상 터뜨리기** |
  | 독 한 번에 터뜨리기(레이븐 「마지막 깃」·아카네 「잔불」) | 터뜨리기는 아카네만. 레이븐은 **독 옮기기·독이 줄지 않음** |
- 카드 UI 특색: 카드 모양으로 누구 카드인지 한눈에(아래 표 「카드 UI」).

## 2. 동료별 표

열: **게이지**(이름·칸·차는 조건) / **각성**(2턴) / **특색**(그 동료만) / **시그니처 콤보 2개** / **바꿀 카드**.

### ★5

#### 시온 — 별 소환사
- **게이지 「별자리」 7칸**(별 7개가 선으로 이어짐): 정령을 부를 때 1, 정령이 3번 행동할 때마다 1.
- **각성 「천구」**: 정령이 턴 끝마다 **두 번** 행동, 정령 최대 6 → 9, 매 턴 시작 정령 1 자동. 각성이 끝나도 정령은 남는다.
- **특색**: 시온만 **내 턴이 끝난 뒤에도 싸우는 아군**을 둔다.
- **콤보 A** 별 정령 부르기 → 별 정령 부르기 → 북극성 → 별똥 소나기 (정령 4 × 행동 2 + 소나기 6타 ≈ 60)
- **콤보 B (각성)** 큰곰자리 → 은하수 → 별자리 완성 (정령 7, 턴 끝 두 번 행동 + 완성 55 ≈ 180)
- **바꿀 카드**
  - 추가 「쌍둥이자리」(1, 정령 2, 다음 턴 정령 행동 +1), 「유성 인도」(0, 이번 턴 모든 정령 피해 +2) → 시온 13장 맞춤.
  - 별자리 완성: 조건 정령 3 → 5, 피해 40 → 피해 정령 수 ×10.
- **카드 UI**: 카드 위에 작은 별 점(정령 수만큼 켜짐).

#### 루나리아 — 달의 무희
- **게이지 「월륜」 4칸**(초승·반달·보름·그믐 달 모양): 달을 그 모양으로 바꾸면 그 칸에 불이 켜짐. 네 칸 다 켜지면 가득.
- **각성 「만월야」**: 2턴 동안 **네 달 효과가 모두 동시에** 걸림. 달을 바꾸는 카드를 쓸 때마다 모든 적 피해 8.
- **특색**: 루나리아만 **전투 중 달을 바꾼다**(파티 전체 효과가 바뀜).
- **콤보 A** 초승의 춤 → 반달 베일 → 보름의 춤 → 그믐의 춤 (패시브로 카드 4장·방어 12, 월륜 가득)
- **콤보 B (각성)** 차고 기우는 달 → 은빛 회전 → 달그림자 스텝 (달 바뀔 때마다 모든 적 8 + 회전 7×2 ≈ 적 셋에 150)
- **바꿀 카드**: 은빛 회전 「이번 턴 달이 바뀐 횟수만큼 한 번 더」 추가. 월식 → 「이번 턴 달 효과 반대로(보름↔그믐, 초승↔반달)」.
- **카드 UI**: 카드 오른쪽 위에 그 카드가 바꾸는 달 모양.

#### 아카네 — 홍련 검성
- **게이지 「홍련」 8칸**: 베기로 화상을 걸 때 1, 화상 틱 피해 10마다 1.
- **각성 「홍련 개화」**: 화상이 줄지 않음. **누구의 베기든** 맞을 때마다 대상 화상만큼 즉시 피해(터뜨림, 화상은 남음).
- **특색**: 아카네만 **화상을 터뜨린다**(잔불·각성).
- **콤보 A** 숯불 → 홍련 베기 → 숯불 → 잔불 (화상 9 → 터뜨림 두 번 ≈ 40)
- **콤보 B (각성)** 붉은 달(화상 2배) → 쌍염 → 홍련 베기 → 업화 일섬 (화상 20+ 를 베기 4타마다 터뜨림 ≈ 160)
- **공명 예시**: 아이리스와 함께 각성 → 「홍백 쌍검」 비용 0·2배, 아이리스 베기 비용 0과 겹쳐 베기 8~10타.
- **바꿀 카드**: 업화 일섬 「대상 화상 2배 뒤 피해 18」로. 대장간의 불 → 「이번 턴 모든 아군 공격이 베기로 친다」(누구든 화상을 걸게).
- **카드 UI**: 베기 카드 테두리에 불꽃 문양, 화상 수치가 카드에 실시간 표시.

#### 엘레오노르 — 시계탑의 마녀
- **게이지 「태엽」 6칸**: 시간 카드를 쓸 때 1, 밤 시계를 10분 되돌릴 때 1.
- **각성 「멈춘 자정」**: 2턴 동안 **밤 시계가 멈춤**(시간 카드 비용 0분, 「새벽」의 시계 효과도 무효). 시간 카드를 쓸 때마다 에너지 +1.
- **특색**: 엘레오노르만 **밤 시계를 되돌리고 적의 턴을 건너뛰게** 한다.
- **콤보 A** 정지된 순간 → 시차 → 정지된 순간 (같은 적을 2턴 정지)
- **콤보 B (각성)** 분침 베기 → 분침 베기 → 시곗바늘 찌르기 → 정오의 종 (시간 카드가 에너지를 돌려줘 무한에 가까운 연쇄, 모든 적 14×n ≈ 130+)
- **바꿀 카드**: 분침 베기를 보통 → 흔함으로(덱에 잘 들어오게). 시차 「이번 턴 쓴 시간 카드 하나를 손패로 + 비용 0」.
- **카드 UI**: 시간 카드에 시계 바늘이 돌아가는 아이콘(지금보다 크게). 각성 중 손패 시계 바늘이 멈춰 보임.

### ★4

#### 아이리스 — 검사
- **게이지 「칼끝」 6칸**: 베기 1번에 1.
- **각성 「무한일섬」**: 베기 비용 0(턴마다 처음 5장). **이번 턴 베기 횟수가 턴이 끝나도 사라지지 않고** 2턴 내내 쌓임. 「세 번째 베기부터 +4」가 +6.
- **특색**: 아이리스 카드는 **아이리스 카드끼리 이어 써도 연계가 끊기지 않는다**(검의 리듬). 같은 동료 연속이 이득인 유일한 동료.
- **콤보 A** 칼집 치기 → 베기 → 연속 베기 → 마지막 일격(비용 0) ≈ 50
- **콤보 B (각성)** 검무(베기 +2) → 베기 ×3 → 천 번 베기 ≈ 140
- **바꿀 카드**: 천 번 베기 「베기 수 ×2」 → 「×3, 각성 중 ×5」. 추가 「칼끝 세우기」(0, 칼끝 +2, 다음 베기 +3).
- **카드 UI**: 베기 카드에 칼끝 눈금(이번 턴 베기 수).

#### 노엘 — 마술사
- **게이지 「꿈」 5칸**(양 다섯 마리): 잠든 채 턴 시작 1, 잠든 턴에 카드를 한 장도 안 쓰면 +1.
- **각성 「몽중 무쌍」**: 잠든 채로 공격 카드를 쓸 수 있고, 별똥 마법·꿈 폭발이 **마력을 비우지 않고 깨우지도 않음**(각성이 끝날 때 비움).
- **특색**: 노엘만 **아무것도 안 하는 턴이 이득**이다(잠든 턴 카드 0장이면 마력 2배).
- **콤보 A** 깊은 잠 → (카드 0장으로 턴 넘김) → 늦잠 → 꿈 폭발 (마력 20 × 5 = 100)
- **콤보 B (각성)** 별똥 마법 → 별똥 마법 → 꿈 폭발 (마력 15를 세 번 = 45+45+75 ≈ 165)
- **바꿀 카드**: 늦잠 「다음 턴 마력 2배」 그대로, 하품 「잠든 상태면 양 +1」 추가.
- **카드 UI**: 잠든 동안 노엘 카드가 반쯤 감긴 눈처럼 흐려지고, 각성 중엔 별빛으로 빛남.

#### 레이븐 — 암살자
- **게이지 「검은 깃」 6칸**: 독을 거는 카드 1장마다 1, 독으로 적이 쓰러지면 2.
- **각성 「흑우」**: **독이 줄지 않음**, 턴 시작 독 피해가 두 번, 목 긋기 비용 0.
- **특색**: 레이븐만 **독을 옮긴다** — 독 걸린 적이 쓰러지면 그 독이 남은 적에게 넘어감(상시).
- **콤보 A** 독 안개 → 맹독 → 목 긋기 (독 12 → 24, 목 긋기 24)
- **콤보 B (각성)** 독의 정원 → 맹독 → 목 긋기 → (적 턴 시작 독 두 번) ≈ 적마다 100
- **바꿀 카드**: 마지막 깃 → 「모든 적 독을 가장 독이 높은 적의 독으로 맞춤. 소멸」(터뜨리기는 아카네에게 넘김).
- **카드 UI**: 카드 아래 깃털 하나, 독 카드는 대상 독 수치 미리 보기.

#### 미미·모모 — 쌍둥이
- **게이지 「손뼉」 4쌍(8칸, 분홍·하늘 번갈아)**: 쌍 효과가 날 때마다 한 쌍(2칸).
- **각성 「거울 세계」**: 모든 미미 카드가 모모 카드로도, 모모 카드가 미미 카드로도 친다 → **매 카드가 쌍**. 쌍 효과 2배.
- **특색**: 쌍둥이만 **한 사람이 두 동료**다(미미 카드와 모모 카드는 연계에서 서로 다른 동료). 전투 첫 턴 연계 1칸(텔레파시)도 쌍둥이만.
- **콤보 A** 미미 찌르기 → 모모 막기 → 거울 춤 → 미미 회전
- **콤보 B (각성)** 손뼉 맞추기 → 미미 회전 → 모모 우산 → 둘이서 하나 (카드 6장 × 5 + 쌍 2배 ≈ 110)
- **바꿀 카드**: 둘이서 하나 「쓴 카드 수 ×4」 → 「×5, 쌍이 난 카드는 2장으로 침」.
- **카드 UI**: 미미 카드는 왼쪽 리본, 모모 카드는 오른쪽 리본. 쌍이 날 카드는 리본이 반짝.

#### 세바스 — 집사
- **게이지 「찻잔」 5칸**: 턴 끝에 손패를 남길 때 1장당 1, 카드를 3장 뽑을 때마다 1.
- **각성 「완벽한 응대」**: 턴 끝에 **손패를 전부 남김**, 손패 상한 없음, **다른 동료 카드** 비용 -1.
- **특색**: 세바스만 **손패를 다음 턴으로 넘긴다**(남기기·예약). 밤 시계는 만지지 않는다.

- **바꿀 카드**: 회중시계 → 「예비 찻잔」(0, 카드 1장, 남기기 +1). 집사의 시계 → 「만찬 준비」(0, 손패를 모두 남기고 다음 턴 에너지 +1, 소멸).

#### 마리아나 — 해적 여왕

- **각성 「약탈의 밤」**: 별빛 쓰는 카드가 **별빛을 쓰지 않고**도 최대 효과. 적에게 준 피해 10마다 별빛 +2.

- **콤보 A** 현상금 → 금화 던지기 → 약탈 (쓰러뜨리면 별빛 +35)
- **콤보 B (각성)** 해적 깃발 → 금화 던지기 ×2 → 함포 지원 → 닻 던지기 ≈ 110
- **바꿀 카드**: 금화 던지기 「별빛 5 → 피해 12」를 「별빛 최대 15까지, 5마다 피해 8」로(쓸수록 셈).

#### 토모리 — 등대지기의 손녀 (17세, 단정)

- **콤보 B (각성)** 회전하는 빛 → 할아버지의 등불 → 모든 적의 노림을 제노에게(제노 역린 + 용혈) — 수비 각성이 남을 터뜨리게 하는 동료

#### 시그룬 — 하늘 창기사

- **콤보 A** 날아오르기 → (다음 턴) 급강하 → 회오리 창
- **콤보 B (각성)** 급강하 → 급강하 → 하늘 가르기 → 발할라 낙하 (착지 없이 18·18·10·모든 적 20 ≈ 120)

#### 제노 — 용의 피 흑기사

- **콤보 B (각성)** 용의 숨결 → 흑룡 베기 ×2 → 흑룡 해방 (잃은 체력 30이면 매타 +9, 해방 18+ ≈ 110)

- **콤보 B (각성)** 바람 읽기 → (0비용 연쇄 10회) → 폭풍 연참 ≈ 30 + 15 + 탈영병의 각오 = 90
- **바꿀 카드**: 추가 「빈손」(0, 카드 1장, 이번 턴 0비용 카드 피해 +1 누적).

## 3. 밸런스 원칙
- **★5가 가장 크게 터진다**: 각성 턴 120~250, 공명하면 300 이상. 게이지가 상대적으로 빨리 참.
- **★3도 각성 뽕맛은 확실**: 브릭처럼 준비가 길지만 한 번 터지면 ★5만큼 크게(최대값은 높고, 안정성은 낮게). 각성 컷인·테마 층·숫자 연출은 성급과 상관없이 같은 크기.
- 각성이 생기는 만큼 **적 체력을 올린다**(1막 +15%, 2막 +25%, 보스 +30~40%). 각성 없이 버티는 턴이 지루하지 않게 일반 턴 수치는 지금 그대로.
- 목표(봇 기준): 판마다 피해 100+ 턴 3~5번, 「새벽」 격파율은 지금 목표(25~35%) 유지, 평균 전투 길이 4~6턴.
- 봇은 "게이지가 차면 공명·적 체력을 보고 켤지 미루기"를 배워야 한다(sim.mjs).

## 4. 적·보스 쪽 대응
각성을 막는 적이 아니라 **각성 타이밍을 고민하게 하는** 적.
| 적·보스 | 대응 |
|---|---|
| 안개 마녀(1막 강적) | 매 턴 체력이 가장 높은 동료 게이지 -2 |
| 시계태엽 천사(3막) | 각성한 동료가 있으면 시계 +10분 대신 +20분 |
| 쌍둥이 풍향계(2막 강적) | 한쪽이 쓰러지면 남은 쪽이 「각성」(적도 각성 연출) |
| 등대지기 | 불빛이 **각성한 동료를 먼저** 비춤(그 동료 카드 비용 +1) → 각성 켤 턴을 고름 |
| 구름 기사단장 | 2단계 「도전」: 각성한 동료를 노리고, 그 동료에게 맞으면 반격 5 |
| 「새벽」 | 동료가 각성할 때마다 밤 시계 +5분. 체력 절반에서 「여명」: 모든 동료 게이지 1칸씩 빨아들여 방어로. 엘레오노르 각성이면 시계 효과 무효(맞수) |

## 5. 화면·소리
- 동료 초상 아래 게이지(동료다운 모양 아이콘), 다 차면 초상 발광 + [각성] 버튼(누르면 에너지 0으로 각성).
- 각성 컷인: ★3·★4 가로 컷인(그림 목록의 컷인 재사용), ★5 전신 CG. 두 번째부터 짧게.
- 각성 중: 화면 테두리 동료 색, 동료 카드 테두리 반짝, 전투곡 위 **동료 테마 층 20개**(8마디 리프, `tools/compose`에 추가, 각 6~8초 루프).
- 공명: 두 사람 컷인을 한 화면에 나란히, 전용 효과음(두 테마 화음).
- 야경(셋 동시 각성): 밤하늘에 별이 쏟아지는 1.5초 연출 + 효과음.
- 100+ 피해: 히트스톱 0.15초, 큰 숫자, 효과음 한 단계 위. 결과 화면 「오늘 밤 최고의 한 턴」.

## 6. 구현 메모 (M9 후보)
- 데이터: `characters.js`에 `gauge: { name, max, icon, on: { slash: 1, poisonCard: 1, … } }`, `awaken: { turns: 2, text, mods }`. 엔진은 이벤트(베기, 장전, 정령 행동, 막은 피해, 시계 되돌림, 뽑기 등)를 내보내고 게이지가 받음.
- 카드 데이터에 `awakenOnly`, `awakenText`(각성 중 바뀐 글) 필드.
- 공명·야경 판정은 `combat.js`. 각성 횟수는 전투 상태에.
- 순서: ① 게이지·각성 엔진 + 5명(처음 동료) → ② 나머지 15명 → ③ 공명·야경·적 대응 → ④ 테마 층 작곡 → ⑤ sim 밸런스.
- 기존 `docs/03`의 카드 수치는 이 문서의 「바꿀 카드」를 반영할 때 함께 고친다.
