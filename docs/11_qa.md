# 11. QA 플레이 리뷰 (M8 뒤)

처음 하는 사람 눈으로, Playwright로 실제 화면을 눌러 가며(치트 없이) 돌았다.
- 경로: 첫 실행 튜토리얼 → 본부 → 10연 소환 → 판 2번(도라·고든·후쿠로 / 아카네·루나리아·아이리스) → 결과 → 에피소드·도감·기록·동료·교환소·설정
- 화면: 1280×720, 844×390(폰 가로). 야시장·사건·강적·보상은 따로 열어 확인.
- 클릭 수(단순하게 첫 카드부터 쓰는 손): 튜토리얼 약 31번, 1막 끝까지 약 150번.

## 바로 고친 것 (fix/qa)
| 무엇 | 어디 | 고친 내용 |
|---|---|---|
| 키워드 설명이 없음 | 카드·상태 칩·적 의도·도구·에너지·연계 | `js/data/keywords.js` 키워드 27개. 마우스를 올리거나 손가락을 대면 도움말이 뜬다(`#tip`). `title`이 붙은 버튼(도구·달·밤의 깊이)도 같은 도움말로 |
| 적의 특수 규칙이 안 보임 | 전투 적 칸 | 「단단한 껍데기」「갑옷 n」「행동 ×2」「시계 +n분」「불빛」「2단계」「가시 n」「쓰러지며 폭발」「훔친 카드 n」 칩 + 설명 |
| 듀오가 언제 나오는지 모름 | 전투 손패 | 지금 쓰면 듀오가 생기는 카드에 금색 테두리 깜빡임 + 「듀오」 딱지 + 도움말 「지금 쓰면 듀오 「검과 방패」」 |
| 마지막 일격으로 듀오가 생기면 컷인이 보상 화면을 가림 | 전투 → 보상 | 전투가 끝났으면 「손에 들어왔다」 컷인을 띄우지 않음 |
| 도움말 줄 [건너뛰기]와 보상 [건너뛰기]가 같은 이름 | 튜토리얼 | 도움말 줄 버튼을 「튜토리얼 그만두기」로 |
| 에너지 칸이 무엇인지 모름 | 전투 왼쪽 아래 | 「에너지」 글자 + 도움말 |
| 파티 화면 패시브 글이 줄 중간에서 잘림 | 파티 고르기 | 두 줄에서 「…」로 자르고, 전문은 도움말. 고른 셋의 패시브 전문을 오른쪽에 표시 |
| 폰 가로에서 [출발]이 밀려 안 보임 | 파티 고르기 오른쪽 | 순서: 고른 셋 → 시작 설정 → [출발] → 인연 → 패시브. 오른쪽 칸 안에서 스크롤 |
| 안 본 에피소드가 목록 아래에 묻힘 | 에피소드 | 안 본 화가 있는 동료 → 가진 동료 → 없는 동료 순 |
| 소환 결과 「흔한 도구」만 크게, 진짜 이름은 작게 잘림 | 소환 결과 | 물건 이름을 크게, 종류를 작게. 글이 칸을 넘지 않게 |
| 한글이 낱말 중간에서 끊김(「무작 위」) | 카드 글 전체 | `word-break: keep-all` |
| 긴 카드 이름이 「잡동사니 …」로 잘림 | 카드 머리 | 6글자 넘는 이름은 글자를 조금 줄임 |
| 지도 대열 줄 끝 「적 ›」이 무슨 뜻인지 모름 | 지도 | 「적은 이쪽 ›」 + 도움말 |
| 담금질 중 [턴 끝]이 왜 꺼졌는지 모름 | 전투 | 안내 줄에 「강화할 카드를 누르면 턴을 이어 갈 수 있다」 |

## 남은 것 (우선순위)
| # | 무엇 | 어디서 | 왜 | 제안 |
|---|---|---|---|---|
| 1 | 클릭이 많고 템포가 늘어진다 | 전투 | 적이 하나여도 카드마다 두 번 눌러야 한다(카드 → 적). 1막에 150번 가까이 누른다 | 설정 「빠른 사용」(기본 켬): 대상이 하나뿐이면 카드를 한 번 눌러 바로 쓴다. 끌어 놓기는 그대로. 적 행동·턴 넘김 연출도 짧게 |
| 2 | 전투 화면에서 캐릭터가 작고 가운데가 비었다 | 전투(특히 폰 가로) | 「캐릭터가 예쁘고 간지 나게」가 핵심인데 동료·적이 화면의 1/6 크기. 동료 칸과 적 칸 사이가 텅 빔 | 동료 그림을 키우고(그림이 들어오면 서 있는 그림 1.5~2배), 적은 가운데 쪽으로. 맞을 때 흔들림·숫자 튀기기·카드가 날아가는 움직임(feat/juice 몫) |
| 3 | 보상·결과·사건·휴식 화면이 밋밋하다 | 보상, 결과, 사건, 휴식 | 글과 네모 칸뿐. 이긴 기분, 고르는 기분이 약함 | 보상 카드 뒤집기 등장, 결과에 막별 진행 막대(0:00→도착)와 쓴 듀오 컷인 썸네일, 다음 10연까지 남은 별 조각. 사건·휴식은 배경 그림(bg 묶음)과 동료 상반신 |
| 4 | 시간 페이스를 알기 어렵다 | 지도·위 띠 | 밤 시계는 보이지만 「지금 빠른지 느린지」가 안 보인다. 봇처럼 시간 카드를 막 쓰면 2막에서 7시 붕괴 | 시계 막대에 막별 목표 눈금(2:00·4:00·6:00)과 현재 위치, 칸 위 「도착 예상」을 막 보스까지 합산해서도 보여 주기 |
| 5 | 적 특수 규칙을 문서와 맞추기 | 적 데이터·docs/04 | 콘텐츠 확장으로 자폭·가시·카드 훔치기·부르기 등이 들어왔다. 칩(「가시 n」「쓰러지며 폭발」「훔친 카드 n」)으로는 보이게 했지만 docs/04 표가 데이터와 다르다 | docs/04를 데이터에서 다시 만들기(03처럼). 행동 아이콘(자폭·부르기)도 의도 칸에 그림으로 |
| 6 | 파티 고르기가 20칸이라 찾기 어렵다 | 파티 고르기 | 성급·역할·인연으로 거를 수 없다. 누가 지금 고른 동료와 인연인지 모른다 | 성급·역할 필터, 고른 동료와 인연 있는 동료에 작은 실 표시 |

## 확인 방법
- `node tools/smoke.mjs` (전 화면 자동 점검)
- 도움말: 전투에서 카드·「독」 칩·적 의도 위에 마우스를 올린다.
- 듀오 미리 보기: 브릭·아이리스·마르타로 출발 → 브릭 카드 → 아이리스 카드를 쓰면 마르타 카드가 금색으로 깜빡인다.
