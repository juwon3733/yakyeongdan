# 05. 판 바깥 (별 소환·기록·난이도)

동료·의상·카드 묶음·도구는 **별 소환(가챠)** 으로 얻는다. 현금 결제는 없고, 판을 하며 모은 별 조각으로만 돌린다.

## 1. 별 조각 (소환 재화)
판이 끝나면(이기든 지든) 받는다.
| 얻는 곳 | 별 조각 |
|---|---|
| 막 보스 격파 | 막마다 10 |
| 「새벽」 격파 | 20 |
| 도착 시각 보너스 | 6:00 전 10분마다 +2 (최대 +20) |
| 새로 찾은 듀오 | 쌍마다 5 (처음 한 번) |
| 강적 격파 | 3 |
| 패배 | 도달한 층 수 ×1 (최소 5) |
| 도감·업적 첫 달성 | 5~30 |

- 보통 한 판에 15~60개. 소환 1번 = 10개 → **판당 1~6번**.
- 첫 실행 선물: 100개(10연 1번).

## 2. 처음 동료
- 무료로 처음부터: **아이리스(★4), 브릭(★3), 마르타(★3)** (파티 3명이 바로 짜짐).
- 첫 10연은 **★4 동료 1명 확정**(노엘·레이븐 중 하나).
- **초심자 소환**: 처음 30번 안에 ★5 동료 1명 확정, 그 첫 ★5는 4명 중 **직접 고른다**.
- 나머지 동료(★5 4명, ★4 8명, ★3 5명)와 이후 추가 동료는 소환으로. 동료 목록과 성급은 03_characters.md.

## 3. 소환 결과와 확률
| 등급 | 확률 | 나오는 것 |
|---|---|---|
| ★5 | 4% | ★5 동료 (시온·루나리아·아카네·엘레오노르) |
| ★4 | 16% | 절반은 ★4 동료, 절반은 동료 의상·희귀 도구·카드 묶음(2장) |
| ★3 | 80% | 30%는 ★3 동료, 나머지는 흔한 도구·별가루(아래)·휴식 대화 조각 |

- **10연**(100개): ★4 이상 1개 확정.
- **천장**: ★5 없이 50번 돌리면 51번째 ★5 확정. 40번째부터 ★5 확률이 매번 +4%씩 오름(부드러운 천장). 천장 횟수는 다음 소환 기간으로 이어진다.
- **새 동료 우선**: 어느 등급이든 동료가 나오면 아직 없는 동료가 70% 확률로 먼저 나온다.
- **픽업**: 일정 기간마다(업데이트 단위, 혹은 2주) ★5 한 명과 ★4 두 명 픽업. ★5의 50%가 픽업 동료. 픽업을 놓치면 다음 ★5는 픽업 확정.
- 모든 확률은 소환 화면에 표시한다.
- 한 판에 소환 1~6번이면, 보통 15~25판(약 10~15시간) 사이에 ★5 하나를 천장 없이 만날 정도.

## 4. 겹치면: 별자리
같은 동료가 또 나오면 그 동료의 **별자리**가 한 칸 올라간다(최대 5).
| 별자리 | 얻는 것 |
|---|---|
| 1 | 두 번째 의상 |
| 2 | 그 동료 카드 묶음 1 해금(보상 풀에 2장) |
| 3 | 시작 카드 1장이 강화판으로 시작 |
| 4 | 전용 도구 해금(그 동료가 파티에 있을 때만 등장) |
| 5 | 듀오 컷인이 특별판으로 바뀜, 이름 옆 별 테두리 |

- 별자리는 **힘을 조금만** 올린다(3·4단계). 0단계로도 「새벽」을 깰 수 있게 밸런스는 0단계 기준으로 맞춘다.
- 별자리 5가 넘게 겹치면 별가루 50.

## 5. 별가루와 교환소
- ★3이 겹치거나 별자리가 꽉 찬 동료가 나오면 별가루로 바뀐다.
- 교환소(본부): 별가루로 원하는 의상·카드 묶음·도구를 직접 산다. ★3 동료 80, ★4 동료 150, ★5 동료 400으로 하나 고를 수 있다(가챠 운이 계속 나쁠 때의 마지막 안전망).

## 6. 소환 연출
- 본부 옥상의 밤하늘. 버튼을 누르면 별똥별이 떨어진다.
- 별똥 색: 흰색(★3) / 보라(★4) / 금색(★5). 금색이면 화면이 잠깐 멈췄다가 하늘이 갈라진다.
- ★3·★4 동료: 컷인 → 서 있는 그림 + 이름·한마디.
- ★5 동료: 하늘이 갈라짐 → 실루엣 → **전용 등장 연출**(전신 CG를 배경으로 이름이 크게) → 서 있는 그림 + 첫 대사.
- 10연은 별똥 10개가 한꺼번에, 누르면 하나씩 펼침. [모두 넘기기] 버튼.

## 7. 본부 화면
- 탑 아래 등대 같은 건물. 메뉴: 소환 / 교환소 / 동료(별자리·의상 갈아입히기) / 도감 / 기록.
- 아래에 가진 동료들이 쉬는 정지 그림.

## 8. 도감
- **동료**: 그림, 말투 한 줄, 별자리, 의상, 쓴 판 수, 이긴 판 수
- **듀오**: 인연 듀오 44칸. 찾은 듀오는 컷인 다시 보기
- **카드**: 본 카드 / 쓴 카드
- **적**: 만난 적, 이긴 적
- **휴식 대화**: 본 대화 다시 보기(★3 「휴식 대화 조각」으로도 열림)

## 9. 기록
- 동료 조합별 최고 도착 시각
- 달별 승리 횟수
- 「밤의 깊이」 최고 단계

## 10. 난이도: 밤의 깊이
「새벽」을 한 번 이기면 열린다. 단계는 누적. 높은 단계를 처음 깨면 별 조각 보너스(단계×5).
| 단계 | 추가 규칙 |
|---|---|
| 1 | 강적 체력 +15% |
| 2 | 칸 시간 +5분 |
| 3 | 시작 체력 -10 |
| 4 | 보스 체력 +15% |
| 5 | 낮잠이 20분만 되찾음 |
| 6 | 시작 덱에 저주 「졸음」 1장 |
| 7 | 일반 적 체력 +10% |
| 8 | 여명 효과가 5:30부터 |
| 9 | 휴식 회복 20% |
| 10 | 「새벽」이 매 턴 +15분 |

## 11. 매일의 밤 (나중에)
- 날짜를 시드로 지도·달·보상이 정해진 판. 하루 한 번 깨면 별 조각 15.

## 12. 동료 추가 계획
- 첫 공개 20명(★5 4, ★4 9, ★3 7) → 업데이트마다 ★5 1명 + ★4 또는 ★3 1명.
- 새 동료 하나 = 카드 9~13장 + 인연 듀오 1~3쌍 + 그림(★3 약 9장, ★4 약 10장, ★5 약 12장: 서 있는 그림, 상반신 3, 컷인, 의상, 카드 대표 4, ★5는 전신 CG).
- 다음 후보(가제): 별 고래를 모는 소녀(★5), 은퇴한 탑 안내인 할머니(★4), 쌍권총 쌍둥이 형제(★4), 안개 마녀(1막 강적의 동료판, ★5).
