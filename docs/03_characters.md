## 성급 차이
| | ★3 | ★4 | ★5 |
|---|---|---|---|
| 성능 | 단순하고 확실한 한 가지 역할 | 키워드 + 고유 상태 하나 | 판을 바꾸는 키워드 |
| 카드 세기 | 기준 | 기준 | **같은 비용 대비 약 +20%** (피해·방어·효과 수치, 효과 하나 더) |
| 패시브 | 작은 편의(전투 시작 방어 4 등) | 키워드를 받쳐 주는 중간 크기 | **파티 전체의 판을 바꾸는 강한 규칙(두 줄)** |
| 카드 풀 | 9~11장 | 11~12장 | 13장 |
| 시작 덱 | 4장 | 4장 | 4장 |
| 그림 | 서 있는 그림, 상반신 3, 컷인 | + 두 번째 의상 | + 두 번째 의상, **전신 CG** |
| 듀오 컷인 | 기본 | 기본 | 특별판(배경·효과 추가) |
| 디자인 | 수수하고 친근 | 화려한 소품 | 가장 공들인 의상·무기·이펙트. 실루엣만 봐도 누군지 알게 |

- **패시브는 모든 동료에게** 하나씩 있다. 성급이 높을수록 세다. ★5 패시브는 파티 전체의 판을 바꿀 정도로.
- 궁극기 카드는 없다.
- **★5 전용 카드는 더 좋다**: 같은 비용의 ★3·★4 카드보다 수치가 약 20% 높거나 덤 효과가 하나 더 붙는다(예: 아카네 「홍련 베기」 1 = 피해 7 + 패시브 화상, 아이리스 「베기」 1 = 피해 6). 그래서 ★5는 패시브와 카드 두 겹으로 강하다. 체력은 성급과 상관없이 캐릭터 역할로 정한다.
- **★5 전신 CG를 쓰는 곳** (카드가 아니라 연출로):
  - 소환 등장: 하늘이 갈라지고 전신 CG를 배경으로 이름이 크게
  - ★5가 낀 인연 듀오: 컷인 대신 전신 CG 버전(두 사람 중 ★5 쪽 CG가 배경)
  - 보스 격파 마무리 일격을 ★5 카드로 넣으면 전신 CG가 1초
  - 결과 화면 MVP(가장 많이 피해·방어를 낸 동료)가 ★5면 전신 CG로
- **밸런스 원칙**: ★5가 들어간 파티가 확실히 강하지만(봇 기준 「새벽」 격파율 +20~25%p), ★3·★4만으로도 「새벽」을 깰 수 있다(★3만 파티도 15% 이상). ★3은 특정 조합의 핵심 부품이 되게 한다(예: 핀이 있으면 듀오가 빨리 열림, 도라가 있으면 시간 카드를 전투 중 강화).

카드 표 읽는 법: 비용 `1` = 에너지 1, `시간` = 밤 시계 20분(초승달 15분, 엘레오노르 −10분). 강화판은 괄호. 방어는 카드 주인에게 걸린다. 「체력 N 회복」은 받을 동료를 고른다(쓰러진 동료는 고를 수 없음). 「체력 N 잃음」은 카드 주인 자신이다.

## 듀오
듀오는 **인연이 있는 짝에게만** 있다. 모든 짝에 듀오가 있는 게 아니다.
- 파티에 인연 짝이 둘 다 있을 때만, 그 둘의 카드를 이어 쓰면 듀오 카드가 생긴다. 인연이 없는 짝은 연계만 차고 듀오는 없다.
- 인연 듀오는 이름·효과·컷인이 짝마다 따로 있다. 지금 44쌍: 처음 8명(창립 멤버라 서로 다 인연) 28쌍 + 새 동료 16쌍.
- 파티 고르기 화면에서 셋 사이 인연 줄이 그어져 보인다. 인연을 찾아 파티를 짜는 것도 재미.
- 새 동료를 넣을 때 인연 1~3쌍을 같이 만든다.

## 휴식 칸 대화 예시
- 아이리스·브릭: 브릭 "또 혼자 앞서 나가지 마!" / 아이리스 "…네 포탄이 늦은 거다."

- 레이븐·세바스: 세바스 "차에 독은 안 넣었습니다." / 레이븐 "…그 말이 더 무섭군."
