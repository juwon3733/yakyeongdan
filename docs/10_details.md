# 10. 세부 규칙 (도구·지도·보상·튜토리얼)

## 1. 카드 희귀도와 보상
- 동료 카드는 **흔함 / 보통 / 희귀** 셋. 시작 카드는 흔함.
- 동료마다 보상 풀 비율: 흔함 50%, 보통 35%, 희귀 15%. ★5는 희귀 비율이 20%.
- 일반 전투 보상 3장: 흔함 60% / 보통 32% / 희귀 8%. 강적: 흔함 40 / 보통 45 / 희귀 15. 보스: 희귀 3장.
- 희귀가 한동안 안 나오면 다음 보상부터 희귀 확률 +2%씩(나오면 초기화).
- 보상 3장은 파티 세 사람에게서 한 장씩 나오는 게 기본(쓰러진 동료 카드도 나옴).
- 카드 표의 희귀도 표시는 M4에서 채운다. 기본 규칙: 비용 2 이상 또는 「소멸」 큰 효과 = 희귀, 시간 카드 = 보통.

## 2. 저주 카드
사건·적에게서 덱에 들어오는 나쁜 카드. 대부분 「쓰면 소멸」(에너지 1)로 치울 수 있다.
| 저주 | 효과 |
|---|---|
| 졸음 | 쓸 수 없음. 손패에 있으면 턴 끝에 시계 +5분 |
| 안개 | 쓰면 소멸(에너지 0). 안 쓰면 턴 끝에 무작위 동료 피해 2 |
| 녹슨 열쇠 | 손패에 있는 동안 카드 1장 덜 뽑음 |
| 깨진 등불 | 손패에 있으면 앞줄 동료 방어 -3 |
| 길 잃음 | 쓸 수 없음. 전투가 끝날 때 덱에 남아 있으면 시계 +10분 |

## 4. 지도 만들기
- 막마다 4층 + 보스. 층마다 2~3칸, 층 사이 선은 갈렸다 합쳐짐(교차 없음).
- 막 첫 층은 전부 전투. 보스 바로 앞 층에 휴식 최소 1칸.
- 강적은 막마다 1~2칸, 2층 이후에만. 야시장은 막마다 최소 1칸 경로상에.
- 같은 종류 칸이 한 경로에 연속 3번 나오지 않게.
- 평균 경로 시간: 1막 약 115분, 2막 약 120분, 3막 약 115분 → 보스 포함 평균 약 5:30 도착. 가장 빠른 경로 약 4:40, 가장 느린 경로 약 6:20.
- 그믐달이면 사건 칸 비율 20% → 30%.
- 지도는 판 시드로 정해진다(같은 시드 = 같은 지도).

## 5. 첫 실행 튜토리얼
- 처음 켜면 타이틀 전에 **짧은 첫 판**(약 5분): 아이리스·브릭·마르타, 정해진 지도 3칸(전투 → 사건 → 전투) + 작은 보스.
- 도움말 줄로 하나씩 알려 줌(인물 대사가 아님):
  1. 카드를 적에게 끌어 놓기 / 누르고 대상 누르기
  2. 적 의도와 노림 얼굴
  3. 서로 다른 동료 카드를 번갈아 → 연계 칸
  4. 아이리스→마르타를 이어 써서 첫 인연 듀오 「검과 방패」 (일부러 손패에 맞춰 줌)
  5. 지도의 시간과 밤 시계
  6. 대열 바꾸기
- 끝나면 별 조각 100(첫 10연) 지급 → 본부로 → 소환 화면 안내.
- 설정에서 다시 보기.

## 6. 숫자 표시 규칙
- 카드 글의 숫자는 힘·약화·연계·달을 반영한 실제 값으로 보이고, 원래보다 오르면 초록, 내리면 빨강.
- 적 의도 숫자도 약화·취약 반영.
- 밤 시계는 디지털(3:40)과 시계 그림을 같이. 칸 위 소요 시간은 "+20분".
