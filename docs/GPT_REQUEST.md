# GPT 그림 요청

전체 목록은 `docs/PROMPTS.md`(자동 생성), 남은 묶음은 `node tools/next-batch.mjs --all`.

## 매번 보내는 글 (그대로 복사, 고칠 것 없음)

```
juwon3733/yakyeongdan 최신 main을 받고 AGENTS.md대로 다음 그림 묶음을 알아서 골라 만들어 줘.

- `node tools/next-batch.mjs`가 고른 「다음 묶음」을 하고, 그 묶음 브랜치를 올리면 **멈추지 말고** 다시 `node tools/next-batch.mjs`를 돌려 다음 묶음을 이어서 해. 「지금 그릴 수 있는 묶음 없음」이 나오거나 대화가 너무 길어질 때까지 계속. 묶음마다 브랜치 따로.
- 도구가 고른 순서대로 해. 어려워 보이는 묶음(특히 전투 스프라이트 pose-…)을 건너뛰고 다른 묶음으로 가지 마. 정말 못 만들면 그 묶음 id와 이유를 끝에 적어.
- 그림은 한 번에 하나씩 만들고, 한 번에 여러 후보(2~3장)를 뽑지 마. 다시 만들기는 그림마다 최대 1번(확실히 다른 사람이거나 꼭 보여야 할 것이 아예 없을 때만). 조건을 다 못 맞춰도 나은 쪽을 올리고 못 맞춘 점만 적은 뒤 바로 다음으로 — 검수·크기 줄이기는 Claude가 해. 크기·여백 중엔 「칸 경계에 닿지 않기」가 먼저야.
- 프롬프트는 assets/prompts.json에서 같은 id의 prompt를 한 글자도 고치지 말고 그대로 써.
- reference_images에 적힌 PNG는 전부 첨부해. 그림체 기준 그림은 reference_images에 이미 들어 있어(동료는 style/akane_c.png, 적·보스·배경은 게임 그림) — 적·보스·배경에 아카네 시안을 따로 붙이지 마. 기준 그림의 인물·색·옷은 따라 그리지 말고 도트 크기·외곽선·명암만 맞춰. 「이미 있음」으로 나온 그림은 다시 만들지 마. 첨부는 한 장에 최대 5장 — 도구가 알려 주는 대로(그림체 기준 → reference_images → 남는 칸만 기준 그림).
- UI 키트(ui-kit)는 틀·버튼·띠의 가장자리가 곧고 대칭이어야 해(늘여서 씀).
- 시트(battlesheet·cardsheet·foesheet·iconsheet·fxsheet)는 한 장에 격자로 여러 개를 그려. 칸 수·순서·크기는 프롬프트대로, 칸 사이 선·글자 없이, 칸 가장자리에 조금 여백을 두고 그림·효과가 칸 경계에 닿지 않게(경계에서 그대로 잘려). assets/sheets/에 시트만 넣고 `npm run art`를 돌리면 칸마다 잘린 파일이 생겨 — 잘린 파일도 같이 커밋해.
- 이펙트 시트(fxsheet)는 캐릭터 없이 효과만, 화려하게. 전투 스프라이트(battlesheet)와 보스는 일러스트가 아니라 굵은 저해상도 도트야. 같은 사람을 단순하게, 칸마다 같은 크기·같은 발 위치.
- 동료 일러스트 묶음(char-…)은 설정화부터 만들고(올리지 마) 그걸 첨부해서 나머지를 한 대화 안에서 차례로.
- 미성년(미미·모모, 핀, 토모리)은 단정하게. 글자·말풍선 금지(로고 묶음 logo의 「야경단」 세 글자만 예외 — 한글을 정확히). 크기는 width×height 정확히, 투명 배경, `npm run check` 통과.
- 브랜치는 assets/<묶음 id>-<월일시분>, 늘 새 이름. main에 직접 올리지 마. PR이 안 되면 브랜치 이름만 알려 줘.
- 묶음마다 끝나면 한 장(시트는 칸)마다 "id — 꼭 보여야 할 것이 어디 있는지" 한 줄, 못 맞춘 건 솔직히.
```

같은 글을 계속 보내면 된다. 한 번에 여러 묶음을 이어서 한다(앞 묶음이 main에 들어와야 하는 묶음은 도구가 건너뛴다). 검수 대기 중인 묶음(원격에 `assets/<묶음>-*` 브랜치가 있는 것)과 기준 그림이 아직 main에 없는 묶음은 도구가 알아서 건너뛴다. 순서는 `tools/next-batch.mjs`의 `ORDER`(★5부터).

## 묶음 종류

| 묶음 | 한 번에 그리는 것 | 게임에서 |
|---|---|---|
| `char-<id>` | 서 있는 그림 + 상반신 보통 표정 (일러스트 2장) | 파티·본부·소환·MVP·대화, 다른 그림의 기준 |
| `pose-<id>` | 전투 스프라이트 시트 1장 (4×2: 서기·숨쉬기·공격·스킬 / 방어·피격·쓰러짐·승리) | 전투 화면의 동료 |
| `fx-common` | 공용 타격 이펙트 시트 4장 (3×2, 베기·폭발·찌르기·마법 6프레임) | 시그니처가 없는 모든 공격 |
| `fx-<id>` | 시그니처 이펙트 시트 1장 (위 3칸 공격 타격 / 아래 3칸 스킬 오라, 캐릭터 없이) | 그 동료 공격·스킬 |
| `cards-<id>` | 카드 그림 시트 1장 (2×2: 공격·방어 / 스킬·필살) | 그 동료 카드 전부(같은 종류끼리 같이 씀) |
| `enemy-act1~3` | 적 시트 2장씩 (3×2, 일반 적 + 강적) | 전투 화면의 적 |
| `boss-<id>` | 보스 스프라이트 2~3장(단계별) + 컷인 | 보스전 |
| `bg` | 배경 13장 | 전투·지도·본부·사건 |
| `cg-star5` | ★5 전신 CG 5장 | 소환 등장·★5 듀오·보스 마무리·MVP |
| `duo` | 인연 듀오 컷인 10장 | 듀오 카드 연출 |
| `title` `summon` `app` | 타이틀, 소환 하늘 + 별똥별 3장, 앱 아이콘 | |
| `icons` `icons-sig` | 아이콘 시트 5장 (4×4) | 도구·동료 전용 도구 |
| `extra-<id>` | 웃음·진지 표정, 컷인 | 아직 게임에서 안 씀 — 뒤로 |
| `skin-<id>` | 스킨(두 번째 의상) | 나중 — 맨 뒤 |
| `style-<id>` | 그림체 시안 | 게임에 안 씀 — 도구가 건너뜀 |
