# GPT 그림 요청

전체 목록은 `docs/PROMPTS.md`(자동 생성), 남은 묶음은 `node tools/next-batch.mjs --all`.

## 매번 보내는 글 (그대로 복사, 고칠 것 없음)

```
juwon3733/yakyeongdan 최신 main을 받고 AGENTS.md대로 다음 그림 묶음을 알아서 골라 만들어 줘.

- `node tools/next-batch.mjs`를 돌려서 나온 「다음 묶음」 하나만 해. 범위는 내가 따로 안 정해.
- 프롬프트는 assets/prompts.json에서 같은 id의 prompt를 한 글자도 고치지 말고 그대로 써.
- reference_images에 적힌 PNG는 전부 첨부해. style/akane_c.png가 일러스트 그림체 기준이야. 「이미 있음」으로 나온 그림은 다시 만들지 말고 기준으로 첨부만 해.
- 시트(battlesheet·cardsheet·foesheet·iconsheet)는 한 장에 격자로 여러 개를 그려. 칸 수·순서·크기는 프롬프트대로, 칸 사이 선·여백·글자 없이, 그림이 칸 밖으로 나가지 않게. assets/sheets/에 시트만 넣고 `npm run art`를 돌리면 칸마다 잘린 파일이 생겨 — 잘린 파일도 같이 커밋해.
- 전투 스프라이트(battlesheet)와 보스는 일러스트가 아니라 굵은 저해상도 도트야. 같은 사람을 단순하게, 칸마다 같은 크기·같은 발 위치.
- 동료 일러스트 묶음(char-…)은 설정화부터 만들고(올리지 마) 그걸 첨부해서 나머지를 한 대화 안에서 차례로.
- 미성년(미미·모모, 핀, 토모리)은 단정하게. 글자·말풍선 금지. 크기는 width×height 정확히, 투명 배경, `npm run check` 통과.
- 브랜치는 assets/<묶음 id>-<월일시분>, 늘 새 이름. main에 직접 올리지 마. PR이 안 되면 브랜치 이름만 알려 줘.
- 끝나면 한 장(시트는 칸)마다 "id — 꼭 보여야 할 것이 어디 있는지" 한 줄, 못 맞춘 건 솔직히.
```

같은 글을 계속 보내면 된다. 검수 대기 중인 묶음(원격에 `assets/<묶음>-*` 브랜치가 있는 것)과 기준 그림이 아직 main에 없는 묶음은 도구가 알아서 건너뛴다. 순서는 `tools/next-batch.mjs`의 `ORDER`(★5부터).

## 묶음 종류

| 묶음 | 한 번에 그리는 것 | 게임에서 |
|---|---|---|
| `char-<id>` | 서 있는 그림 + 상반신 보통 표정 (일러스트 2장) | 파티·본부·소환·MVP·대화, 다른 그림의 기준 |
| `pose-<id>` | 전투 스프라이트 시트 1장 (4×2: 서기·숨쉬기·공격·스킬 / 방어·피격·쓰러짐·승리) | 전투 화면의 동료 |
| `cards-<id>` | 카드 그림 시트 1장 (2×2: 공격·방어 / 스킬·필살) | 그 동료 카드 전부(같은 종류끼리 같이 씀) |
| `enemy-act1~3` | 적 시트 2장씩 (3×2, 일반 적 + 강적) | 전투 화면의 적 |
| `boss-<id>` | 보스 스프라이트 2~3장(단계별) + 컷인 | 보스전 |
| `bg` | 배경 13장 | 전투·지도·본부·사건 |
| `cg-star5` | ★5 전신 CG 5장 | 소환 등장·★5 듀오·보스 마무리·MVP |
| `duo` | 인연 듀오 컷인 10장 | 듀오 카드 연출 |
| `title` `summon` `app` | 타이틀, 소환 하늘 + 별똥별 3장, 앱 아이콘 | |
| `icons` `icons-sig` | 아이콘 시트 5장 (4×4) | 도구·동료 전용 도구 |
| `extra-<id>` | 웃음·진지 표정, 컷인, 두 번째 의상 | 아직 게임에서 안 씀 — 맨 뒤 |
| `style-<id>` | 그림체 시안 | 게임에 안 씀 — 도구가 건너뜀 |
