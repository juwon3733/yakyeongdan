# 퀄리티 계획 — "AI가 만든 게임" 티 없애기

전체 화면 12장(npm run shots)을 보고 정리했다. 티가 나는 건 그림 하나가 아니라 **화면 짜임새 전체**다.

## 왜 AI 게임처럼 보이나 (영향 큰 순)
1. **모든 화면이 같은 틀** — 남색 네모 + 얇은 금색 테두리 + 작은 글씨. 본부 메뉴·파티·상점·결과·소환 설명이 전부 웹페이지 같은 상자 목록.
2. **글이 너무 많다** — 파티 오른쪽 설명 벽, 결과 화면 글 줄, 소환 확률 표, "별 조각은 판을 하면 얻는다. 현금은 쓰지 않는다." 같은 만든 사람 말투.
3. **그림체가 섞여 있다** — 타이틀·본부·소환은 매끈한 애니 일러스트, 전투는 도트, 카드·상점은 2등신 임시 도트.
4. **볼거리가 한 군데 없다** — 화면마다 시선이 갈 중심(큰 그림·큰 숫자·큰 버튼)이 없고 다 같은 크기.
5. **멈춰 있다** — 화면 넘김이 뚝 끊기고, 본부·타이틀·지도에 살아 있는 움직임(빛·먼지·바람)이 없다.
6. **UI가 코드로 그린 네모** — 버튼·띠·틀이 CSS 테두리. 진짜 게임은 그린 틀(UI 키트)을 쓴다.

## 원칙
- 화면마다 **중심 하나**(큰 그림 또는 큰 버튼), 글은 3줄 이하, 설명은 「?」 안으로.
- **그린 UI 키트**(틀·버튼·띠·제목 장식)로 CSS 네모를 바꾼다.
- 그림체 하나: 화면 밖도 **도트 일러스트**(지금 일러스트 그림을 도트로 다시).
- 모든 화면에 **움직임**: 넘김 연출 + 배경의 작은 움직임.

## 단계
### 1. 그림 (GPT, 내일 한도 풀리면 — 순서 바꿈)
1. 카드 그림 19명 (손패·상점·보상에 늘 보임)
2. **UI 키트** 시트: 틀(9칸으로 늘이는 틀) 3종·버튼 3상태·제목 띠·탭·숫자 보석 / **로고** 「야경단」 도트 글자
3. 타이틀 도트 키아트, 본부 배경 도트판
4. 나머지 몸 스프라이트·오라·동반자·투사체·적 자세

### 2. 화면 다시 짜기 (Claude가 설계, 주니어 A가 구현)
| 화면 | 지금 | 바꿈 |
|---|---|---|
| 본부 | 오른쪽에 메뉴 상자 6개 | 방 안 사물을 누르는 식(문=출격, 망원경=소환, 책장=에피소드), 아래 작은 아이콘 줄 |
| 파티 | 22칸 격자 + 설명 벽 | 아래 무대에 고른 셋이 서 있고, 위에 얼굴 줄 하나, 설명은 고른 동료 한 명만 짧게 |

| 소환 | 그림 + 설명 표 | 그림 + 버튼 둘만, 확률은 「?」 |

### 3. 손맛·움직임 (Claude)
- 화면 넘김 연출(밤하늘 와이프), 버튼 누름 반응, 배경 움직임(등불 깜빡임·먼지·물결)
- 전투: 그림 들어오는 대로 층별 기술 연출, 적 자세, 턴 띠·숫자
- 말투: 만든 사람 설명 → 게임 속 말(동료 대사·짧은 이름)
