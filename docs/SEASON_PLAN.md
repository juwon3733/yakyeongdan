# 온라인·시즌 계획 (Asteria 방식 참고)

목표: 「탑 하나 처음부터 오르기」에서 → **시즌마다 새 동료·새 보스·새 랭킹**으로 계속 돌아오는 게임.
원칙: 현금 없음(별 조각만), GitHub Pages 그대로(빌드 없음), 서버는 **Supabase**(Asteria와 같은 방식 — 게스트로 바로 시작, 원하면 계정 연결).

## 1. 온라인 기반 (먼저)
| 무엇 | 어떻게 |
|---|---|
| 계정 | 게스트(기기 저장) → 이메일·구글로 계정 연결하면 저장이 서버로 옮겨짐 (Asteria 「게스트 데이터로 회원가입」) |
| 저장 | 진행(P)을 서버에 저장·불러오기, 기기와 서버 중 새 것을 고르게(말없이 덮어쓰지 않음) |
| 서버 시간 | 시즌·매일·주간 경계와 보상 판정은 서버 시계로 |
| 기록 검증 | 판은 씨앗(seed)으로 똑같이 다시 돌릴 수 있다 → 「씨앗 + 고른 것·쓴 카드 기록」을 같이 올리고, 서버(Edge Function)가 다시 돌려 점수가 맞는지 확인 |
| 이름·신고 | 닉네임(금칙어), 랭킹에서 신고 → 숨김 |

## 2. 랭킹 (시즌마다 새로)
| 랭킹 | 겨루는 것 |
|---|---|
| **밤 오르기** | 가장 빠른 「새벽」 도착 시각(밤의 깊이별로 따로) |
| **끝없는 탑** | 가장 높은 층 |
| **시즌 보스** | 한 판에 시즌 보스에게 준 피해 합(단계별), 클리어 시간 |
| **매일의 밤** | 오늘 같은 씨앗·규칙으로 가장 빠른 시각 (모두 같은 판이라 공정) |
| **주간 퍼즐** | 같은 문제를 가장 적은 턴·카드로 |
- 보상: 순위 구간(상위 1%·10%·50%·참여)마다 별 조각 + 시즌 칭호·카드 뒷면·초상 테두리 (능력치 보상 없음)
- 친구·같은 동료 랭킹: 「아이리스를 쓴 사람 중」처럼 동료별 필터

## 3. 시즌 (6주 한 시즌)
| 시즌마다 | 내용 |
|---|---|
| **시즌 동료** | ★5 또는 ★4 1명 새로(픽업 소환 첫 2주 확률업), 시즌 테마에 맞는 패시브·카드 12장·전용 필살 |
| **시즌 보스** | 탑 꼭대기 너머의 새 보스 1(일반·어려움·악몽 3단계, 단계마다 첫 클리어 보상), 3단계 변신·전용 컷인 |
| **시즌 탑 규칙** | 시즌 내내 붙는 탑 규칙 하나(예: 「달이 두 개」 매 막 달을 둘 고름) |
| **시즌 패스(무료)** | 판을 하면 오르는 시즌 별(경험치) → 30단계 보상: 별 조각·의상·카드 뒷면·시즌 동료 별자리 조각 |
| **시즌 이야기** | 시즌 동료 에피소드 3화 + 시즌 보스 짧은 이야기 |
| 시즌 끝 | 랭킹 보상 지급 → 기록은 「지난 시즌」에 남음, 시즌 동료는 상시 소환에 들어감 |

시즌 1 예시 「유성우의 밤」: 시즌 동료 ★5 별똥 기사(가칭) · 시즌 보스 「떨어진 별의 왕」 · 탑 규칙 「유성우: 매 턴 무작위 적에게 3 피해, 가끔 동료에게도」

## 4. 새 콘텐츠 (시즌과 함께 차례로)
1. **보스 러시 「달의 회랑」** — 보스 5연전, 기록 랭킹
2. **동료 시련** — 동료 한 명 전용 탑(22명), 깨면 칭호·의상 색
3. **주간 퍼즐 「밤의 수수께끼」** — 같은 문제, 랭킹
4. **야경 순찰(방치)** — 쉬는 동료를 보내 두면 별 조각·대사
5. **원정** — 두 팀이 번갈아 지도를 탐험(Asteria 원정처럼 다시뽑기·스킬 순서 저장)

## 5. 운영
- 게임 안 공지(본부 게시판, 한 줄 + 자세히), 디스코드 공지는 사용자가
- 버전·시즌 표시, 점검 시간(서버 꺼져도 오프라인으로 혼자 하기는 됨)

## 순서
1. Supabase 연결: 게스트·계정·저장·서버 시간 (Claude)
2. 매일의 밤 랭킹 (씨앗이 같아 검증이 쉬움) → 끝없는 탑·밤 오르기 랭킹
3. 시즌 틀: 시즌 정보 표, 시즌 패스, 랭킹 보상 지급
4. 시즌 1 콘텐츠: 시즌 동료·시즌 보스(그림은 GPT 「season1」 묶음), 보스 러시
5. 동료 시련 · 주간 퍼즐 · 야경 순찰 · 원정

## 사용자가 정할 것
- Supabase 프로젝트: Asteria 프로젝트를 같이 쓸지, 야경단용을 새로 만들지(무료 한도는 프로젝트 2개)
- 계정 로그인 방법: 이메일·구글·디스코드 중 무엇
- 시즌 길이(6주 제안)와 시즌 1 테마
