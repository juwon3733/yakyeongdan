# 밤샘 작업 계획 (2026-10-31 밤) — 퀄리티·AI티·어색한 곳

원칙: 하나 끝날 때마다 화면 캡처로 직접 확인 → `npm run check`·`text-check`·`smoke` 통과 → main.
전투 배치(인물 크기·서는 줄·숫자 글꼴)는 다른 세션이 손대는 중이라 그쪽 CSS는 건드리지 않고, 연출(`js/juice.js`·`css/fx.css`) 위주로 한다.

## A. 전투 연출 (가장 먼저)
1. 승리 → 보상: 지금은 「승리」 띠가 빈 무대 위에 뜬다. 동료가 승리 자세로 남아 있고, 쓰러진 적 자리에 빛 조각이 흩어지며 사라지게.
2. 적 처치: 흰 번쩍 → 몸이 조각으로 부서짐 + 이펙트, 마지막 적은 짧은 슬로 모션과 줌.
3. 동료 23명 공격·스킬 연속 캡처 점검: 제자리로 튀어 돌아가기·미끄러짐·떠 있음·이펙트 위치 어긋남(그림 크기가 바뀌었으니 전부 다시).
4. ★5 필살 6종·듀오(에스텔 2쌍 포함)·보스 단계 전환을 새 크기에서 다시 맞춤.
5. 피해 숫자: 큰 피해일수록 크고 굵게, 연타는 쌓여 보이게, 막힌 피해는 방패 색.

## B. AI티·어색한 곳
6. 글자 잘림: 동료 목록 이름(「아이…」), 지도 위 보스 이름(위 띠에 가려짐) 등 text-check가 못 잡는 것까지 화면별로.
7. 표 같은 화면: 소환 확률 화면을 글 표 → 별 아이콘·막대로. 결과 화면 숫자 줄 정리.
8. 문구: 화면 설명 글 말투 통일(한다체), 같은 말 반복·과한 설명 빼기(데이터 대사는 건드리지 않음).
9. 빈 곳: 보상·결과·도감 화면에서 휑한 자리에 배경 동료·빛·움직임.

## C. 점검
10. 폰 가로(844×390·740×360) 화면 전부 캡처 → 겹침·잘림 수정.
11. 프레임 측정(tools/fps.mjs): 그림 해상도를 올린 뒤 느려졌는지.
12. 밸런스 보고서 다시(npm run balance) → docs/BALANCE.md.

아침 보고: 고친 것 목록 + 전후 캡처 몇 장 + 못 한 것.

## D. 전투 디테일 (추가)
13. 적 공격 모션을 종류별로: 돌진(근접)·원거리(투사체)·마법(시전 빛)·여러 번 때리기(연타 리듬), 센 공격은 예고 떨림 + 붉은 테두리.
14. 방어막: 생길 때 반짝 막, 깨질 때 유리 조각 이펙트, 다 막으면 「막음」 금속음+불꽃.
15. 상태 이상: 독·화상·약화·취약·출혈이 걸릴 때 아이콘이 적에게 날아가 박힘, 턴마다 독·화상 피해에 작은 이펙트.
16. 회복: 초록 빛이 아래에서 올라오고 체력 막대가 차오름(지금은 숫자만).
17. 에너지: 쓸 때 등불 구슬이 깨지듯 꺼짐, 턴 시작에 다시 켜짐.
18. 카드 흐름: 뽑을 때 덱에서 날아옴, 버릴 때 버림 더미로, 덱이 비어 섞을 때 섞는 연출.
19. 연계 칸 차오름·3칸 달성 빛, 듀오 카드가 손에 생길 때 두 동료 색 빛기둥.
20. 「적의 차례」「내 차례」 띠를 짧고 굵게, 턴 수 표시 정리.
21. 6시 여명: 하늘·화면 색이 붉게 바뀌고 적 강화 표시, 7시가 가까우면 화면 가장자리 경고.
22. 동료 쓰러짐(무릎 꿇고 흐려짐)·부활(빛기둥) 연출.
23. 화면 흔들림·히트스톱 세기를 피해 크기에 맞춰 단계화(작은 공격은 약하게).

## E. 화면별 다듬기 (추가)
24. 타이틀: 로고 반짝임, 별똥별이 가끔 지나감, 메뉴 고를 때 소리·밑줄 움직임.
25. 본부: 메뉴에 작은 도트 아이콘, 대표 동료 숨쉬기·눈 깜빡임 느낌(살짝 위아래), 시간대 조명.
26. 파티 고르기: 동료를 고르면 칸에 내려앉는 연출, 인연 짝이 생기면 줄이 빛남.
27. 지도: 이동할 때 말이 칸으로 뛰어감, 보스 칸 강조(맥박), 칸 아이콘 마우스 올리면 커짐.
28. 상점: 사면 카드가 덱으로 날아가고 상인 말풍선 반응, 돈 부족하면 흔들림.
29. 휴식·사건: 휴식 모닥불 불꽃·쉬는 동료, 사건 선택지 결과가 보이는 연출.
30. 소환 결과: 카드가 한 장씩 뒤집힘(희귀도별 빛), 새 동료는 「NEW」 도장.
31. 에피소드 대화: 말하는 사람 강조(안 말하는 사람 어둡게), 대사창 글자 하나씩, 표정 바뀔 때 통통.
32. 결과 화면: 숫자 차오름(카운트업), 업적은 하나씩 오른쪽 아래로.

## F. 점검·정리 (추가)
33. 에피소드 23명×3화 전부 자동 재생해 오류·빈 대사·잘림 확인.
34. 카드 23명 전체 툴팁: 키워드 설명이 다 붙는지, 효과 글과 실제 수치가 맞는지(시뮬로 확인).
35. 소리 연결: 화면마다 곡, 버튼 누름·카드 올림 소리가 빠진 곳.
36. 핀 강화(가장 약한 동료): --patch로 시험 → 수치 결정 → 시뮬 확인.
37. 시즌 시작(11/1) 직전 점검: 시즌 소개·픽업 소환·시즌 보스 세 난이도·패스 받기 실제로 한 번씩 플레이.
38. 온라인 준비(키 없이 되는 것): 로그인 화면(아이디·비번) 틀, 저장 동기화 모듈(연결 안 되면 그대로 이 기기 저장).
