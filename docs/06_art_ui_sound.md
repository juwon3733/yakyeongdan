# 06. 그림·화면·소리

## 그림 원칙
- **저해상도 도트**: 원본을 작게 그리고 정수배(nearest-neighbor)로 키운다. 안티앨리어싱 없음, 적은 색, 디더링.
- **캐릭터는 모바일 가챠게임풍 서브컬처 디자인**: 큰 눈, 매력적인 얼굴, 소품 디테일. 예쁘고 간지 나게.
- 여성 캐릭터 대부분 장발. 성인 여성은 몸에 맞는 옷, 어깨·배·다리 노출까지(노골적인 건 없음). **미성년(미미·모모)은 단정하게.**
- 그림은 GPT 이미지로 받는다. 코드로 그린 그림은 그림이 없을 때 쓰는 임시용.
- 색감: 밤. 남색·보라 바탕, 등불의 주황, 별빛의 흰색·금색. 막마다 바탕색이 다름(항구=청록 남색, 구름=회보라, 별=검푸른 + 금).

## GPT 그림 파이프라인
같은 방식으로 돌린다: 사용자가 GPT 에이전트에게 `AGENTS.md`대로 묶음 id를 맡김 → `assets/…` 브랜치로 올림 → Claude가 열어 보고 게임 화면에서 확인 후 main에 병합.
- 프롬프트 원본은 `js/asset_prompts.js` 한 곳. 문서용 목록은 스크립트로 생성.
- 검수: 같은 사람으로 보이는지(서 있는 그림·상반신·컷인), 투명 배경, 도트 규칙(색 단계·디더), 미성년 단정.
- 그림체가 어긋나면 디더 변환 스크립트로 맞춘다.

## 화면 (폰 세로 기준)
### 타이틀
- 키아트 + [밤 오르기] [본부] [도감] [설정]

### 본부
- 소환 / 교환소 / 동료 / 도감 / 기록. 아래에 동료들이 쉬는 그림(정지 그림).

### 파티 고르기
- 8칸 초상. 고르면 아래에 그 동료 키워드와 시작 카드 4장.
- 셋을 고르면 그 셋 사이 인연 줄이 그어지고, 인연 듀오를 찾은 것/못 찾은 것 표시.

### 지도
- 세로 스크롤. 맨 위에 **밤 시계**(시계 그림 + 디지털 시각), 그 옆 달 모양.
- 칸 아이콘 + 소요 시간. 누르면 "도착 예상 3:45" 미리 보기 → 한 번 더 누르면 이동.

### 전투
- 위: 밤 시계, 체력, 방어, 별빛
- 가운데: 적(의도 아이콘 위에) / 아래쪽에 동료 셋 나란히(작게), 각자 고유 수치 배지
- 연계 칸 3개(동료 색으로 채워짐)
- 아래: 손패 5장 부채꼴. 카드 테두리 색 = 동료 색. 시간 카드는 시계 아이콘과 금색 테두리
- 듀오가 생기면 손패에 반짝이며 들어오고, 쓰면 컷인

### 보상 / 야시장 / 휴식 / 사건
- 한 화면에 선택지 카드 2~3개. 휴식은 동료 둘이 앉은 정지 그림 + 대화

### 결과
- 도착 시각을 큰 시계로, 쓴 듀오 아이콘, 별 조각 계산

## UI 규칙
- 둥근 모서리·흐린 그림자 대신 도트 테두리와 오프셋 그림자.
- 글꼴: 한글 도트 글꼴(Galmuri, OFL)을 파일로 넣음. 숫자는 큰 도트 숫자.
- 조작 설명은 인물 대사가 아니라 도움말 줄로.
- 손가락 버튼 최소 44px.
- 설정: 효과음·음악 크기, 화면 흔들림 끄기, 애니메이션 줄이기, 글자 크기.

## 연출
- 듀오 컷인: 화면을 비스듬히 가르는 띠에 두 동료 컷인이 좌우에서 밀려 들어와 겹침. 0.8초.
- 시간 카드: 화면 위 시계 바늘이 휙 돌고 주변이 살짝 밝아짐(새벽이 가까워지는 느낌).
- 여명: 6시 넘으면 배경 하늘 끝이 붉게 물들기 시작.
- 막 사이: 다음 층으로 올라가는 짧은 장면(엘리베이터/계단, 2초, 누르면 건너뜀).

## 소리
- PC-98식 FM 음원으로 직접 작곡(numpy FM 신시사이저, game2의 `tools/compose/` 재사용).
- 곡 목록(첫 버전 9곡): 타이틀, 본부, 지도(막마다 편곡 3), 전투, 강적, 보스(막마다 3), 새벽 최종전, 승리, 결과.
- 밤 시계가 5시를 넘으면 전투곡 템포가 조금 빨라짐.
- 효과음 약 20개: 카드 내기, 베기, 포격, 방어, 독, 정령, 시간 카드(시계 소리), 듀오(두 음 화음), 연계 칸 참(음이 하나씩 올라감) 등.
