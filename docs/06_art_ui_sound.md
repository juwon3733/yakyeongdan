# 06. 그림·화면·소리

## 그림 원칙
- **저해상도 도트**: 원본을 작게 그리고 정수배(nearest-neighbor)로 키운다. 안티앨리어싱 없음, 적은 색, 디더링.
- **캐릭터는 모바일 가챠게임풍 서브컬처 디자인**: 큰 눈, 매력적인 얼굴, 소품 디테일. 예쁘고 간지 나게.
- 여성 캐릭터 대부분 장발. 성인 여성은 몸에 맞는 옷, 어깨·배·다리 노출까지(노골적인 건 없음). **미성년(미미·모모)은 단정하게.**
- 그림은 GPT 이미지로 받는다. 코드로 그린 그림은 그림이 없을 때 쓰는 임시용.
- 색감: 밤. 남색·보라 바탕, 등불의 주황, 별빛의 흰색·금색. 막마다 바탕색이 다름(항구=청록 남색, 구름=회보라, 별=검푸른 + 금).

## GPT 그림 파이프라인
같은 방식으로 돌린다: 사용자가 GPT 에이전트에게 `AGENTS.md`대로 묶음 id를 맡김 → `assets/…` 브랜치로 올림 → Claude가 열어 보고 게임 화면에서 확인 후 main에 병합.
- 프롬프트 원본은 `js/asset_prompts.js` 한 곳. `node tools/export-prompts.mjs` → `assets/prompts.json`(에이전트용)·`docs/PROMPTS.md`(사람용). CI가 `--check`로 동기화를 검사한다.
- 에이전트 지시서 `AGENTS.md`, 사용자가 GPT에 보낼 요청 글과 추천 순서 `docs/GPT_REQUEST.md`, 파일 검사 `node tools/check-assets.mjs`(CI).
- 검수: 같은 사람으로 보이는지(서 있는 그림·상반신·컷인), 투명 배경, 도트 규칙(색 단계·디더), 미성년 단정.
- 그림체가 어긋나면 디더 변환 스크립트로 맞춘다.

## 화면 (가로 우선)
- 기준 화면 **16:9, 논리 해상도 640×360** (도트 원본 기준, 정수배로 키움: 1280×720 = ×2, 1920×1080 = ×3). 이 판 안에 UI를 배치하고, 남는 가장자리는 배경 그림을 늘려 채운다.
- 폰은 가로로 돌려서 한다. 세로로 들면 "가로로 돌려 주세요" 한 줄과 돌리는 그림. PC·태블릿은 창 크기에 맞춰 정수배.
- 16:9보다 옆으로 긴 화면(폰 가로 2:1 등)은 판 폭을 최대 800까지 늘려 남는 옆자리를 쓴다(높이 360 그대로). 판 배율이 1.5 미만인 작은 화면은 설정 「글자 크기: 자동」이 **글자 크게**(작은 글자 +1.5~2px, 카드·동료 칸 조금 넓게)를 켠다. 폰 가로 844×390·667×375에서 전투·지도·본부·소환·에피소드를 확인함.
- 카드는 누르기(카드 → 대상) 말고도 **끌어 놓기**로 쓸 수 있다: 적·동료 위에 놓으면 그 대상, 대상 없는 카드는 손패 위 판 아무 데나.
- 손가락으로도 되게: 카드 최소 폭 56(논리 px), 버튼 최소 높이 24(논리 px ×2 이상 → 실제 44px 넘게).

### 파티 고르기
- 왼쪽: 동료 초상 격자(5×4 = 20칸), 성급 테두리 색(★3 은, ★4 보라, ★5 금). 안 가진 동료는 실루엣.
- 오른쪽: 고른 셋이 대열(앞·가운데·뒤)로 선 큰 그림. 위아래로 끌어서 자리 바꿈.
- 아래: 셋 사이 인연 줄, 찾은/못 찾은 인연 듀오, 각자 패시브 한 줄.

### 지도
- **가로 스크롤**(왼쪽→오른쪽으로 오름). 화면 위 띠에 **밤 시계**(시계 그림 + 디지털 시각) · 달 · 별빛 · 동료 셋 얼굴과 체력 막대.
- 칸 아이콘 + 소요 시간. 누르면 "도착 예상 3:45" → 한 번 더 누르면 이동.
- 오른쪽 위 [대열] 버튼: 전투 전에 자리 바꾸기.

### 전투
```
┌──────────────────────────────────────────────┐
│ 밤 시계 3:40 · 달 · 연계 ■■□        별빛 · 덱 │  위 띠
│                                              │
│  [뒤][가운데][앞]          [적1][적2][적3]    │  가운데: 왼쪽 동료 대열, 오른쪽 적
│  체력·방어·배지            의도+노림 얼굴      │
│                                              │
│ 에너지 ③  [카드][카드][카드][카드][카드]  [턴 끝] │  아래: 손패
└──────────────────────────────────────────────┘
```
- 동료는 서 있는 그림을 크게(원본 96×128 ×1.5~2배), 앞줄이 적에 가장 가깝게.
- 적 의도 위에 노리는 동료 얼굴이 작게. 그 동료 발밑이 붉게 깜빡임.
- 카드를 끌어 적 위에 놓으면 공격, 아군 위에 놓으면(대상: 아군 카드) 그 동료에게. 누르기만 해도 됨(누르고 → 대상 누르기).
- 카드 테두리 색 = 동료 색, 시간 카드는 시계 아이콘·금색 테두리, 쓰러진 동료 카드는 회색.
- 듀오가 생기면 손패 오른쪽 끝에 반짝이며 들어오고, 쓰면 컷인(★5 인연 듀오는 전신 CG).

### 보상 / 야시장 / 휴식 / 사건
- 가운데에 선택지 카드 2~5장 가로로. 배경은 그 칸 그림.
- 휴식: 왼쪽에 동료 둘이 앉은 정지 그림 + 아래 대화창, 오른쪽에 [쉬기] [낮잠] [손질].

### 결과
- 왼쪽: MVP 동료(★5면 전신 CG), 오른쪽: 도착 시각 큰 시계, 쓴 듀오 아이콘, 별 조각 계산, 열린 에피소드.

### 에피소드
- 비주얼 노벨식: 배경 전면 + 상반신 둘(좌우) + 아래 대화창. [자동] [빨리] [기록].
- 연출(`js/render/episodes.js`, 대본 명령은 `js/data/episodes.js` 머리말): 대사는 글자 하나씩(누르면 그 줄 전체, 한 번 더 누르면 다음 줄), 말하는 사람 상반신이 살짝 튐, 이름은 동료 색 띠. 줄 세 번째 칸으로 감정(놀람 흔들림·슬픔 어두워짐·웃음 통통), 줄 명령 `{ fx }`로 화면 효과(흔들림·번쩍·암전·흰 페이드), `{ bg }`는 이전 배경이 체크무늬 디더로 사라짐, `{ bgm }`으로 곡 바꾸기. 애니메이션 줄이기면 글자·효과 없이 바로.

## 연출
- 듀오 컷인: 화면을 비스듬히 가르는 띠에 두 동료 컷인이 좌우에서 밀려 들어와 겹침. 0.8초.
- 시간 카드: 화면 위 시계 바늘이 휙 돌고 주변이 살짝 밝아짐(새벽이 가까워지는 느낌).
- 여명: 6시 넘으면 배경 하늘 끝이 붉게 물들기 시작.
- 막 사이: 다음 층으로 올라가는 짧은 장면(탑 실루엣이 아래로 흘러가고 막 이름, 1.5초).

### 구현 (`js/juice.js`)
- 엔진은 연출 사건만 쌓는다(`run.js` `pushFx`, 화면에서 하는 판일 때만): play hitFoe kill hurt tick block heal foeAct foeTurn turn time rewind combat phase. 화면을 새로 그린 뒤 `juice.js`가 시간 순서로 보여 준다(적 차례는 한 행동씩 차례로).
- 연출 층 `#fx` 하나: 반 해상도 캔버스(입자·궤적, 도트처럼 굵게, 입자가 있을 때만 그림) + DOM(숫자·배너·날아가는 카드, Web Animations의 transform·steps).
- 카드: 손패 부채꼴, 올리면 들림, 뽑을 때 덱(뽑을 더미)에서 날아옴, 쓰면 대상(적·동료·적 전체·주인)으로 날아가 터짐, 턴 끝에 버린 더미로. 끌어 놓으면 놓은 자리에서 출발.
- 타격: 흰 번쩍임 + 밀림(적은 오른쪽, 동료는 왼쪽), 숫자는 피해량에 비례해 크게(취약이면 노랑, 출혈 빨강, 막으면 「막음」), 방어가 깨지면 방패 조각, 쓰러지면 회색으로 주저앉음·적은 번쩍이다 부서짐. 큰 피해(10 이상)는 판이 흔들림.
- 동료별 공격: 베기 궤적(아이리스·아카네·라일라·쌍둥이·세바스), 포격 궤적+폭발(브릭·마리아나·후쿠로), 정령 별 꼬리(시온), 독 안개(레이븐), 창 궤적(시그룬), 마법 고리(노엘·루나리아·엘레오노르·토모리), 묵직한 충격(나머지). 독·화상 틱, 회복 반짝임, 방어 얻으면 방패 도트.
- 적: 공격 의도는 흔들리고(한 번에 15 이상이면 붉게 빨리), 행동 직전 앞으로 튀어나옴. 체력 막대는 줄어들고 흰 잔상이 늦게 따라옴.
- 배너: 전투 시작·N턴 내 차례·적의 차례·승리·해가 뜬다. 보스 등장 띠(이름+한 줄), 보스 2단계 띠, 연계 칸이 찰 때 톡.
- 전투가 끝나 보상으로 넘어가면 마지막 전투 화면을 잠깐 얼려 두고 그 위에서 마무리 연출 → 「승리」 → 보상 카드가 한 장씩 내려앉음.
- 효과음은 연출 시간에 맞춰 `juice.js`가 낸다(`audio.js`는 고르기·연계·듀오·마력·카드 내기만 바로).
- 설정: 애니메이션 줄이기면 연출 층을 끄고 소리만, 화면 흔들림 끔이면 밀림·흔들림 없이 번쩍임만.
