# 08. 만드는 순서

각 단계 끝에 "main은 항상 플레이 가능"을 지킨다.

| 단계 | 내용 | 끝났다는 기준 |
|---|---|---|
| M0 뼈대 | 저장소, 폴더 구조, 프로토타입을 데이터/엔진으로 쪼개 옮김, Pages 배포 | 프로토타입과 같은 게임이 새 구조로 돈다 |
| M1 전투 | 적 여러 마리·대상 고르기, 상태 5종, 카드 강화, 5명 카드 전부, 듀오 10쌍 | 1막을 끝까지 깰 수 있다 |
| M1.5 소환 맛보기 | 본부 + 별 소환 기본(확률·연출)만 먼저 | 판을 끝내면 소환을 돌릴 수 있다 |
| M2 판 | 지도 3막, 밤 시계·여명·7시 패배, 사건 12, 야시장, 휴식 3택, 도구 24, 보스 3 | 0시~새벽까지 한 판이 돈다 |
| M3 시뮬 | `tools/sim.mjs`, 첫 밸런스 패스 | 봇 기준 막별 승률·도착 시각이 목표 범위 |
| M4 20명 | 나머지 동료(★5 4, ★4 9, ★3 7) 카드 전부, 패시브·궁극기, 인연 듀오 44쌍, 휴식 대화 | 모든 조합이 돌고, 성급별 승률이 목표 범위 |
| M5 판 바깥 | 별 조각, 별 소환(확률·10연·천장·픽업·별자리), 교환소, 도감, 기록, 밤의 깊이 10단계 | 소환한 동료가 판을 넘어 남는다 |
| M6 그림 1차 | GPT로 동료·적·보스·배경·대표 카드 약 80장, 검수 | 임시 그림이 거의 안 보인다 |
| M7 소리 | 곡 9개, 효과음 20개 | |
| M8 다듬기·공개 | 첫 실행 안내(전투 1판 튜토리얼), 설정, 성능, 폰 점검 | 남에게 링크를 보낼 수 있다 |

## 밸런스 목표 (보통, 봇 기준)
- 1막 보스 도달 90%, 2막 보스 도달 60%, 「새벽」 격파 25~35%
- 평균 도착 시각 5:30 전후. 6시 넘는 판이 20% 정도
- 같은 성급 안에서 어떤 동료도 승률이 그 성급 평균의 ±20%를 넘지 않음
- ★5 포함 파티 「새벽」 격파율이 ★5 없는 파티보다 20~25%p 높음. ★3만 파티도 15% 이상

## 미정 (사용자에게 물을 것)
1. 공유 체력으로 갈지, 동료별 체력(한 명 쓰러지면 그 동료 카드가 막힘)으로 갈지
2. 게임 이름 확정(가제 「야경단」), 영문 이름
3. 화면: 폰 세로 고정 vs 가로도 지원
4. 이야기 비중: 지금은 최소. 동료별 짧은 개인 에피소드(해금형)를 넣을지
5. 「새벽」의 정체에 작은 반전을 둘지 (예: 탑의 주인은 첫 야경단원)
