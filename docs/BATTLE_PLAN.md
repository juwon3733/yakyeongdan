# 전투 다시 만들기 계획 (에픽세븐·카오스 제로 나이트메어 참고)

목표: AI 티 없이 **자연스럽고 부드러운 전투**. 캐릭터가 직접 공격하는 느낌.
원칙: 그림과 연출 코드가 맞아야 한다 — 몸·장식·동반자·이펙트를 **층(layer)으로 나눠** 따로 움직인다.

## 지금 문제 (확인한 것)
| 문제 | 원인 |
|---|---|
| GPT 원본은 좋은데 게임에선 화질이 구림 | 전투 스프라이트가 96×128 저해상도 + 비정수 배율(5.33배 축소·캐릭터마다 다른 보정 배율)로 표시 |
| 끊기는 느낌(10프레임 같음) | CSS 애니메이션 상당수가 `steps()`(일부러 뚝뚝 끊는 도트 연출), 칸 바꿈 교차 페이드, 카드가 날 때 `steps(7)`, 입자는 반 해상도 |
| 흐물흐물·지글거림 | 서로 다른 그림(서기·숨쉬기 칸)을 0.9초마다 섞음 + 그림 한 장을 회전·비정수로 늘림 + 숨쉬기 세 겹 |
| 숫자·이펙트가 허공에 뜸 | 위치 기준이 투명 여백 포함 상자 |
| 적은 그림 한 장이 미끄러짐 | 적 동작 칸 없음, 상대 앞에서 안 멈춤 |
| 네레아처럼 몸·반짝이·고래가 한 그림 | 시트에 장식·동반자까지 같이 그려 짐 → 몸이 움직이면 고래도 같이 비틀림 |

## 새 구조: 캐릭터 한 명 = 층 5개
| 층 | 내용 | 움직임 | 그림 |
|---|---|---|---|
| 1 몸 | 캐릭터만(장식·이펙트·동반자 없이) | 동작 칸 교체(정수 픽셀 이동만, 회전·늘이기 없음) | 몸 시트(고해상도) |
| 2 오라 | 몸 주변 반짝이·빛 | 4~6프레임 반복 | 오라 시트 |
| 3 동반자 | 네레아 고래, 시온 별 정령, 엘레오노르 톱니 등 | 몸과 따로 떠다님·공격 때 따로 돌진 | 동반자 시트 |
| 4 기술 이펙트 | 시전 오라·투사체·적중 | 프레임 재생 | 이펙트 시트(지금 것 + 투사체) |
| 5 화면 연출 | 컷인·암전·카메라·히트스톱·숫자 | 코드 | 컷인 일러스트 |

에픽세븐식 기술 순서: **준비 자세(0.15초) → 시전 자세 + 무기 궤적 → 투사체/돌진 → 적중(히트스톱 0.06초, 적 피격 자세·밀려남) → 숫자 → 복귀**.

## 단계
### 1단계 — 코드만으로 (Claude, 지금)
1. `steps()` 애니메이션 전부 부드러운 곡선으로, 카드 날기 부드럽게
2. 숨쉬기 칸 섞기·회전·비정수 늘이기 없앰 → 대기는 1px 위아래만
3. 도구로 스프라이트마다 실제 몸 영역(발 위치·키) 계산 → 숫자·이펙트·돌진 거리·발 줄 맞춤, 정수 배율
4. 적은 상대 앞에서 멈추고, 맞은 쪽이 밀려남
5. 전투 기록 줄 숨김, 선택 점선 네모 없앰
6. 성능: 동시에 터지는 효과 줄이기(잔상 3→1, 1px 입자 줄임), 필터 그림자 줄이기

### 2단계 — 화면 흐름 (Claude + 주니어)
- 타이틀 → **본부(허브)**: 출격(던전), 별 소환, 동료, 에피소드, 기록, 설정을 고르는 화면 (아스테리아처럼)

### 3단계 — 그림 다시 (GPT, 층별)
- `body-<id>`: 몸만 8동작 시트(256×384 칸, 칸 꽉 채움, 발 위치 고정, 장식·이펙트·동반자 없이)
- `aura-<id>`: 몸 주변 반짝이 6프레임(몸 없이)
- `pet-<id>`: 동반자가 있는 동료만(네레아 고래, 시온 별 정령 등) 대기·공격 각 3프레임
- `proj-<id>`: 원거리 투사체 3프레임(브릭 포탄, 시온 별, 네레아 작살 등)
- `foe-pose`: 적 공격·피격 자세(적마다 2칸)
- 카드 그림 시트(이미 계획됨)

### 4단계 — 기술 연출 다시 (Claude)
- 층 구조로 동료마다 기술 연출: 몸 동작 + 무기 궤적 + 투사체 + 동반자 + 적중 + 컷인
- ★5는 전용 연출(네레아: 고래가 따로 솟아 덮침 등)
